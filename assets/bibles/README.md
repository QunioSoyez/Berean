# Bundled Bible texts

Generated by `npm run build:bibles` (scripts/build-bibles.mjs). Don't edit by hand.

Format: `<version>/<BOOK>.bjson` — JSON array of chapters, each an array of verse
strings (`[chapter-1][verse-1]`). An empty string means the verse isn't in that version.
Book ids are USFM codes (GEN, EXO … REV).

| Version | Source | Status |
| --- | --- | --- |
| KJV — King James Version (1769) | [scrollmapper/bible_databases](https://github.com/scrollmapper/bible_databases) | Public domain* |
| ASV — American Standard Version (1901) | scrollmapper/bible_databases | Public domain |
| YLT — Young's Literal Translation (1898) | scrollmapper/bible_databases | Public domain |
| WEB — World English Bible | npm [`world-english-bible`](https://www.npmjs.com/package/world-english-bible) (from eBible.org) | Public domain; name is a trademark of eBible.org |

\* The KJV is public domain everywhere except the United Kingdom, where it is under
Crown patent.
